# Edge Reader

Edge Reader is an NVDA add-on that allows you to easily save any spoken text as high-quality MP3 files using Microsoft Edge Neural TTS voices.

## What's New (v1.1.0)
* **Multi-Language Support:** When converting large texts or documents, the add-on automatically detects the languages present in the text, allowing you to choose a specific voice for each language.
* **Favorite Voices:** Pin your most frequently used voices to the top by adding them to the Favorites list in the settings.
* **New Shortcut:** Convert currently selected text directly to MP3 without manually copying it.

## Keyboard Shortcuts
* **NVDA+Windows+R:** Toggles the MP3 auto-saving mode (saves every utterance).
* **NVDA+Windows+S:** Saves the last spoken phrase as an MP3 file.
* **NVDA+Windows+C:** Compiles clipboard text to MP3.
* **NVDA+Windows+X:** Compiles the currently selected text on the screen directly to MP3 (no need to copy first).
* **NVDA+Windows+F:** Select a TXT, PDF, or DOCX file from your computer and convert it to MP3.
* **NVDA+Windows+O:** Opens the destination folder for saved MP3s (Default: Downloads/EdgeReader_MP3_Results).
* **NVDA+Windows+E:** Opens Edge Reader settings.

## Settings
NVDA Menu -> Preferences -> Settings -> Edge Reader:
* Configure your default voice, rate, pitch, and favorites list.
* Enable Cyrillic to Latin transliteration or Roman numeral conversion.
