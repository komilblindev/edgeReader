# Edge Reader - NVDA Add-on

[![License: GPL v2](https://img.shields.io/badge/License-GPL%20v2-blue.svg)](https://www.gnu.org/licenses/gpl-2.0.html)
[![NVDA Compatibility](https://img.shields.io/badge/NVDA-2019.3%20--%202026.1-green.svg)](https://www.nvaccess.org/)

**Edge Reader** is a specialized NVDA screen reader add-on designed to convert spoken text, clipboard content, selected text, and whole documents (PDF, DOCX, TXT) into high-quality MP3 audio files using **Microsoft Edge Neural TTS** voices.

---

## 🌟 Key Features

- **Document to Audio Conversion**: Convert entire books or documents (`.txt`, `.pdf`, `.docx`) into MP3 audio tracks (`NVDA + Windows + F`).
- **Direct Selection / Clipboard to MP3**: Quickly compile selected screen text (`NVDA + Windows + X`) or clipboard text (`NVDA + Windows + C`) to MP3.
- **Smart Multi-Language Support**: Automatically detects multiple languages in a single text and reads each segment with its corresponding natural native voice.
- **Automatic MP3 Recording Mode**: Auto-save utterances read by NVDA into separate MP3 files (`NVDA + Windows + R`).
- **Favorite Voices**: Star and organize preferred voices by language for fast selection.
- **Transliteration & Pronunciation Tools**: Cyrillic to Latin transliteration, Roman numeral pronunciation, and rate/pitch adjustments.
- **Multi-language Interface**: Full support for Uzbek, Russian, and English.
- **NVDA Compatibility**: Compatible with NVDA 2019.3 up to 2026.1+.

---

## ⌨️ Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `NVDA + Windows + R` | Toggle MP3 auto-saving mode |
| `NVDA + Windows + S` | Save the last spoken phrase as MP3 |
| `NVDA + Windows + C` | Compile clipboard text to MP3 |
| `NVDA + Windows + X` | Compile selected text directly to MP3 |
| `NVDA + Windows + F` | Convert TXT, PDF, or DOCX document to MP3 audiobook |
| `NVDA + Windows + O` | Open output folder with saved MP3 files |
| `NVDA + Windows + E` | Open Edge Reader settings |

*All shortcuts can be customized in NVDA Menu -> Preferences -> Input Gestures.*
